# JohnBrowser - A Secure Web Browser

A lightweight, privacy-focused web browser built with PyQt6 and Chromium web engine. JohnBrowser provides a clean, distraction-free browsing experience with a modern blue-themed interface.

## Features

- **Tabbed Browsing**: Open multiple tabs for efficient web navigation
- **Modern UI**: Dark blue theme with a clean, intuitive interface
- **Navigation Controls**: Back, Forward, Reload, and Stop buttons
- **Address Bar**: Search Google or enter URLs directly
- **Home Button**: Quick navigation to your homepage
- **Lightweight**: Built with PyQt6 for fast performance
- **Privacy-Focused**: Designed with user privacy in mind

## System Requirements

- Python 3.7 or higher
- PyQt6
- PyQtWebEngine

## Installation

```bash
pip install PyQt6 PyQtWebEngine
```

## Running JohnBrowser

```bash
python JohnBrowserMain.py
```

## Usage

- **Open a URL**: Type in the address bar and press Enter
- **Search Google**: Type your search query in the address bar and press Enter
- **Navigate**: Use the ← and → buttons to go back and forward
- **Reload Page**: Click the ↻ button to refresh the current page
- **New Tab**: Double-click the tab bar to open a new tab
- **Close Tab**: Click the × button on any tab to close it
- **Stop Loading**: Click the ✖ button to stop the current page load

## Project Structure

- `JohnBrowserMain.py` - Main application file with all browser functionality
